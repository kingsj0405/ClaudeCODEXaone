# 채널별 공유 문구

글을 쓴 뒤의 일은 네 번 더 쓰는 것이다. 채널마다 읽는 방식이 다르고, 같은 문장을 복사하면 네 번 다
읽히지 않는다. 이 파일은 문구를 만들 때 지키는 규격이다.

**게시는 하지 않는다.** 초안을 만들어 사용자에게 넘기고, 게시는 사용자가 한다. 링크를 여는 순간
그 사람의 이름으로 남는 일이기 때문이다.

## 공통

- 금지문자는 본문과 같다: `《》` `『』` `「」` `[^1]` 한자 병기.
- 문단은 1~3문장 단위로 끊고 빈 줄을 넣는다. 피드에서 긴 문단은 읽히지 않는다.
- 첫 두 줄이 전부다. 모바일에서 접히는 지점(약 140자) 안에 사건과 목적이 보여야 한다.
- 이모지는 라벨 앞에 하나. 문장 끝에 붙이지 않는다.
- "이 글도 AI와 함께 썼다"를 밝힐 때는 역할을 구체적으로 쓴다 — 무엇을 말할지, 어떤 문장에 이름을
  걸지는 사람이 정했다는 식으로.

## LinkedIn

| 항목 | 규격 |
|---|---|
| 분량 | 900~1,100자 (한도 3,000자) |
| 첫 줄 | 사건 또는 숫자. 접히기 전에 왜 쓰는지가 보여야 한다 |
| 문단 | 1~2문장 + 빈 줄 |
| 링크 | 본문 1개. 함께 볼 글·저장소는 첫 댓글에 묶는다 |
| 첨부 | 1200×630 이미지를 사진으로 첨부. 링크 카드는 도달이 떨어진다 |
| 해시태그 | 5개 이하. 문장 끝에 몰아 쓰지 말고 맨 아래 한 줄 |
| 톤 | 회사 업무 설명은 두 문장을 넘기지 않는다. 독자는 이력서를 읽으러 오지 않았다 |

첫 댓글은 본문 게시 직후 직접 단다. 댓글 링크는 클릭이 집계되지 않으므로, 본문 링크는 반드시
하나 남긴다.

## X

| 항목 | 규격 |
|---|---|
| 분량 | 가중 280자 (한글 2자 = 1, URL 23자 고정) |
| 형태 | 단문 1개 또는 2~5트윗 타래 |
| 첫 트윗 | 논지 한 문장. 링크를 첫 트윗에 넣지 않는다 |
| 링크 | 마지막 트윗 |
| 첨부 | 이미지 1장. 카드만 있으면 노출이 떨어진다 |

타래는 문단을 옮겨 담는 것이 아니라, 트윗마다 한 걸음씩 나아가야 한다. 1/5가 5/5의 요약이면
아무도 끝까지 읽지 않는다.

## Threads

| 항목 | 규격 |
|---|---|
| 분량 | 400~500자 |
| 첫 줄 | 개인 경험 또는 정서. LinkedIn보다 사적이고 가볍다 |
| 끝 | 질문 하나 또는 여운. 링크는 본문 끝이나 첫 댓글 |
| 첨부 | 선택 |

Threads는 대화를 여는 채널이다. 답장이 달릴 자리를 남긴다 — 단정으로 닫지 않는다.

## Instagram

| 항목 | 규격 |
|---|---|
| 피드 분량 | 800~1,200자 |
| 첫 줄 | 장면. 계절·시간·냄새 같은 것 |
| 링크 | "프로필 링크에서" — 캡션 링크는 눌리지 않는다 |
| 피드 이미지 | 1080×1350 (4:5). 캐러셀 5장이면 본문에서 문장 하나씩 발췌 |
| 스토리 | 1080×1920 + 링크 스티커 |
| 해시태그 | 7~10개, 맨 아래 한 줄 |

캐러셀은 표지 1장 + 본문 발췌 3~4장 + 마지막에 글 제목·프로필 안내. 발췌는 문장을 새로 쓰지
않고 본문에서 그대로 가져온다 — 카드와 본문이 다르면 읽은 사람이 속았다고 느낀다.

## 배포 순서

한 번에 네 곳에 올리면 반응이 어디서 왔는지 알 수 없고, 첫 채널의 반응을 보고 문구를 고칠 기회도
없다. 기본 순서는 이렇다.

1. **한 채널 먼저** (보통 Threads 또는 LinkedIn) — 12~24시간 반응을 본다.
2. 반응에서 나온 문장(댓글의 표현)을 다른 채널 첫 줄에 반영한다.
3. 나머지 채널을 하루 안에 배포한다.
4. 같은 글을 다시 올릴 때는 각도를 바꾼다. 수능 전에는 '습관과 신뢰', 수능 뒤에는 '결과 너머의 삶'.

시의성이 있는 글은 이 순서를 뒤집는다. 사건 당일이 지나면 글의 값이 사라지므로, 그때는 네 채널을
동시에 내고 문구만 채널별로 바꾼다.

## 산출물 형식 (distribution.md)

채널마다 세 블록으로 나눈다.

```markdown
## 1. LinkedIn — 1,042자

### 본문
(붙여넣기 가능한 전문)

### 첫 댓글
(링크 2~3개)

### 게시 설정
| 항목 | 값 | 이유 |
```

본문은 코드 블록에 넣는다. 사용자가 복사할 때 서식이 섞이지 않게.
